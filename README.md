# ⛽ Análise de Preços de Combustíveis

Dashboard desenvolvido em Power BI para análise dos preços de combustíveis comercializados em diferentes estados, bandeiras e revendas.

---

# 📖 Sobre

O projeto apresenta uma análise dos preços de combustíveis, permitindo acompanhar a variação dos valores praticados pelas revendas e comparar diferentes produtos, estados e bandeiras.

O dashboard foi desenvolvido com base em dados públicos disponibilizados pelo dados.gov.br, utilizando recursos de Business Intelligence para transformar os dados em informações visuais e facilitar a análise dos preços.

---

# 🎯 Objetivos

- Analisar os preços médios dos combustíveis
- Comparar preços entre diferentes estados
- Identificar as revendas com preços acima da média
- Analisar a variação entre preço máximo e mínimo
- Comparar preços entre diferentes bandeiras
- Acompanhar a evolução dos preços ao longo dos dias
- Facilitar a identificação de variações nos preços dos combustíveis

---

# 📊 KPIs

- Total de amostras
- Revendas acima da média
- Preço médio dos combustíveis
- Preço máximo
- Preço mínimo
- Diferença percentual entre preço máximo e mínimo
- Preço médio por bandeira
- Preço médio por estado
- Evolução do preço médio por dia

---

# ⛽ Combustíveis analisados

- Gasolina
- Etanol
- Diesel
- Diesel S10

# 🛠 Tecnologias

- Power BI
- Excel
- Power Query
- DAX

---

# 📈 Análises

O dashboard permite realizar análises utilizando filtros de:

- Produto
- Estado
- Revenda
- Bandeira
- Período

Além disso, são apresentados gráficos e tabelas para comparação dos preços entre estados, bandeiras e períodos.

# 🔄 Tratamento dos Dados

Os dados foram tratados e transformados utilizando o Power Query, realizando processos de limpeza, organização e preparação das informações para utilização no dashboard.

Foram utilizadas medidas em DAX para criação dos indicadores e cálculos apresentados no relatório.
